# Nextdoor and Facebook group replies

For threads like "what is that plane circling over [place]?". Reply only when
you can help: a real question, a real time and place. Friendly, factual, one
link. Never post the same text twice in a group, never reply to the same
thread twice, and do not reply to threads about enforcement complaints.

If the group bans links or self-promotion, leave a reply without the link or
skip it. Say that you built the tool.

## Build the link first

The "What flew over?" page takes a place and a time and lists what passed
within a few miles, closest first, from public ADS-B:

    https://www.smokysignal.app/seen?lat=LAT&lon=LON&date=YYYY-MM-DD&time=HH:MM

Optional: `&w=` window in minutes and `&r=` radius in miles, or `&place=Fife`
instead of coordinates.

Open https://www.smokysignal.app/seen, pick the date, the time and tap the
place, then copy the page URL; it carries the state. The time is Pacific, 24
hour. Check the result before you reply, so you only say what it says.

## Templates

### It is in the list

> That one was probably N305DK, a Washington State Patrol Cessna working a
> pattern over [place] around [time]. Public flight data for [date]:
> [seen link]. Aircraft like it fly speed enforcement along I-5 and other
> highways. I built the page, no ads, no sign-up.

### It is something else

> From public flight data it looks like [tail], a [medevac / survey /
> sheriff] aircraft, near [place] at [time]. Here is the list for that time
> and place: [seen link]. I built the page; if it is wrong, tell me and I
> will check the tail.

### Nothing tracked was there

> Nothing in the tracked fleet passed over [place] around [time] on [date]:
> [seen link]. It can still be an aircraft we do not track, or one with its
> transponder off, so that is not proof. Worth asking the neighbors who saw
> the time.

### It is circling right now

> If it is still up, this page lists what is circling right now:
> smokysignal.app/circling. I built it; public flight data only.

### When someone asks if it is allowed or creepy

> It is all public broadcast data that anyone with a receiver can hear, and
> the page says where each aircraft's facts came from. It does not store
> where you are, and there are no accounts.

## Do not

- Do not suggest anyone slow down "only when it is up", or anything that
  reads as getting away with speeding.
- Do not reply under posts about a crime or an emergency.
- Do not use "police" jokes. Say "state patrol" or "sheriff".
